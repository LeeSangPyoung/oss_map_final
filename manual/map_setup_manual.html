MAP 엔진 설치 매뉴얼

1. Local PC에서 설치 시, Windows PowerShell 창을 띄운다.

2. Windows에 WSL(Windows Subsystem for Linux) 을 설치한다.

wsl --install --name rocky_wsl2

3. 현재 시스템에 설치된 WSL의 버전을 확인한다.

wsl --version

4. 새로 설치하는 리눅스 배포판을 기본적으로 WSL2 모드로 설치되도록 지정한다.

wsl --set-default-version 2

5. Rocky Linux WSL 이미지 및 관련 데이터를 저장할 공간으로 'D:\rocky_wsl2' 디렉터리를 생성하고, 작업 경로를 해당 디렉터리로 이동한다.

mkdir D:\rocky_wsl2
cd D:\rocky_wsl2

6. Rocky Linux 9의 WSL용 기본 이미지(.wsl 파일)를 공식 저장소에서 다운로드하여, 다운로드 파일을 'D:\rocky_wsl2' 폴더 안에 저장한다.

Invoke-WebRequest
-Uri "https://dl.rockylinux.org/pub/rocky/9/images/x86_64/Rocky-9-WSL-Base.latest.x86_64.wsl"
-OutFile "D:\rocky_wsl2\Rocky-9-WSL-Base.latest.x86_64.wsl"

7. Rocky Linux 9.2 WSL 배포판을 WSL2 환경에 새로 설치한다.

wsl --import Rocky9-2 D:\rocky_wsl2\1 D:\rocky_wsl2\Rocky-9-WSL-Base.latest.x86_64.wsl --version 2

8. 방금 가져온 Rocky9-2 배포판을 실행한다. 실행 후에는 Linux 쉘 환경(Rocky Linux 9.2 터미널)로 들어가게 된다.

wsl -d Rocky9-2

9. 아래 명령어를 순차 실행하여 Rocky Linux WSL 환경에서 기본 패키지 업데이트 → 유틸리티 설치 → SSH 활성화 → Ansible 설치 → Python/Pip 설치 → Java 설치 및 확인한다.

1) 시스템 업데이트

sudo dnf -y update
sudo dnf -y upgrade

2) 기본 유틸리티 설치

sudo dnf -y install vim curl wget unzip git net-tools which tar

3) OpenSSH 서버 설치 및 실행

sudo dnf -y install openssh-server
sudo systemctl enable sshd
sudo systemctl start sshd

4) Ansible 설치

sudo dnf -y install epel-release
sudo dnf -y install ansible-core
ansible --version

5) Python & Pip 설치

sudo dnf -y install python3 python3-pip
pip3 install --upgrade pip

6) Java 설치

sudo dnf -y install java-17-openjdk java-17-openjdk-devel
java -version
javac -version

10. Linux 쉘 환경(Rocky Linux 9.2 터미널)에 진입한다. (MobaXterm 활용)

11. Ansible에서 PostgreSQL 관련 모듈/플러그인을 모아 둔 community.postgresql 컬렉션을 설치한다.

ansible-galaxy collection install community.postgresql

12. 플레이북(yml)과 관련 파일을 둘 작업 폴더를 만들고 해당 경로로 이동한다.

mkdir -p /workspace/yml
cd /workspace/yml

13. 현재 위치에 oss_map_final 폴더를 새 git 리포지토리로 초기화하고 GitHub 원격 저장소를 origin으로 등록한다.

git init oss_map_final
cd oss_map_final
git remote add origin https://github.com/LeeSangPyoung/oss_map_final.git

14. 저장소 전체가 아니라 원하는 경로만 체크아웃 하도록 설정을 켠다.

git config core.sparseCheckout true

15. 저장소 내 ansible/ansible_install_yml/ 하위 파일만 가져온다.

echo "ansible/ansible_install_yml/*" >> .git/info/sparse-checkout

16. 원격 저장소의 main 브랜치에서 sparse 설정에 해당하는 경로만 실제 파일로 가져온다.

git pull origin main

17. Ansible 인벤토리 파일 hosts를 만들고, 대상 호스트를 localhost로 지정하여 yml 실행을 준비한다.

cd /workspace/yml/oss_map_final/ansible/ansible_install_yml
sudo tee ./hosts >/dev/null <<EOF
localhost ansible_connection=local
EOF

18. PostgreSQL 16을 설치/설정하는 플레이북을 실행한다.

ansible-playbook -i hosts ./install_postgresql16.yml
--extra-vars '{"db_port":"5433","db_user":"tesapp","db_password":"experdb12#","db_name":"tesd"}'

19. 방금 설치한 DB에 스키마/테이블/기본 데이터를 생성한다.

ansible-playbook -i hosts ./create_db_data.yml
--extra-vars '{"db_host":"127.0.0.1","db_port":"5433","db_user":"tesapp","db_password":"experdb12#","db_name":"tesd"}'

20. localhost DB에 저장된 테이블이 정상 조회되는지 확인한다. (DBeaver 활용)

21. GeoServer 지정 버전을 설치하고 서비스를 구성한다. (홈 디렉터리, 실행 사용자, 서비스 포트(8089) 등을 변수로 지정)

ansible-playbook -i hosts ./install_geoserver.yml
--extra-vars '{"geoserver_version":"2.24.2","geoserver_user":"geoserver","geoserver_home":"/workspace/geo/geoserver","geoserver_port":"8089"}'

22. 설치된 GeoServer에 대해 권한/디렉터리/플러그인/설정파일 배치 등 초기 구성을 수행한다.

ansible-playbook -i hosts ./configure_geoserver.yml
--extra-vars '{ "geoserver_home": "/workspace/geo/geoserver", "geoserver_user": "geoserver"}'

23. http://localhost:8089 로 접속하여 GeoServer 정상 설치여부를 확인한다.

24. 지도 프론트엔드를 설치/빌드/환경변수를 구성한다.

ansible-playbook -i hosts ./install_ossmap_fe.yml
--extra-vars '{"install_dir":"/workspace/ossmap_fe","geoserver_url":"http://localhost:8089","be_url":"http://localhost:8082","db_host":"127.0.0.1","db_port":"5433","db_name":"tesd","db_user":"tesapp","db_password":"experdb12#"}'

25. OpenStreetMap(OSM) 기반 지도 서비스를 설치/구성한다. (로컬 저장 공간상 타겟 지역 및 줌레벨 일부만 지정)

ansible-playbook -i hosts ./install_osm_map.yml
--extra-vars '{"map_kind":"osm","map_dir":"/workspace/ossmap","map_port":8090,"min_zoom":12,"max_zoom":15,"region":["서울특별시","부산광역시"]}'

26. Map 백엔드 JAR 애플리케이션을 백그라운드로 실행하면서, 표준 출력과 오류 로그를 한 곳(be.log)에 저장한다.

java -jar /workspace/ossmap_fe/be/be-artifact-0.0.1-SNAPSHOT.jar > /workspace/ossmap_fe/be/be.log 2>&1 &

27. 프론트엔드 npm 기본서비스 포트인 http://localhost:5174 로 접속, OSS MAP 페이지를 띄워서 local에 구축한 지도엔진 기능을 확인한다. (MAP 기능은 사용 매뉴얼 참고)
