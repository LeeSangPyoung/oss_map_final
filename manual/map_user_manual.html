MAP 사용 매뉴얼

1. MAP 사용환경 구축한 서버가 local일 경우 npm 기본서비스 포트인 5174를 통해 http://localhost:5174 로 접속 시 기본도 및 레이어가 조회된다.

2. 상단의 베이스 맵에 구축한 기본도 유형 별로 항목이 제공되며, 항목 선택 시 해당 유형의 기본도로 지도 화면이 전환된다.

3. 베이스 맵으로 다울맵 선택 시 다울맵 기본도로 지도 화면이 전환된다.

4. 우측 상단의 '개발자가이드' 토글을 클릭한다.

5. 우측 상단의 '개발자가이드' 토글 클릭 시 지도 화면 좌측에 화살표 버튼이 조회된다.

6. 지도 화면 좌측에 조회되는 화살표 버튼 클릭 시 개발자를 위한 API 가이드 설명이 제공된다.

7. 지도 정보 조회 및 이동과 관련한 기능 리스트가 조회된다.

8. 리스트에서 기능 클릭 시 해당 기능 구현을 위한 API 코드 예시가 제공되며, 팝업의 재생 버튼 클릭 시 API를 통해 반환 되는 값을 확인할 수 있다.

9. 레이어와 관련한 기능 리스트가 조회된다.

10. 리스트에서 기능 클릭 시 해당 기능 구현을 위한 API 코드 예시가 제공되며, 팝업의 재생 버튼 클릭 시 API를 통해 반환 되는 값을 확인할 수 있다.

11. 지도 상에 레이어를 선택하고, 거리와 면적을 측정하고, Point/Line/Polygon을 그리는 기능에 대한 리스트가 조회된다.

12. 우측 상단의 토글에서 'OSSMAP' 토글을 클릭한다.

13. 우측 상단의 원형 버튼은 레이어 컨트롤 버튼으로, DB에 저장되어 있는 레이어 리스트가 조회되며, 해당 레이어 리스트에 대한 컨트롤이 가능하다. (버튼은 지도 상에서 드래그하여 이동 가능)

14. 우측 상단의 'OSSMAP' 토글 클릭 시 좌측에 지도 컨트롤을 위한 기능 버튼이 있는 사이드바가 노출된다.

15. 사이드바에 제공되는 기능은 개발자가이드에서 제공하는 API로 개발된 기능들이며, 레이어 선택, 드로잉, 거리/면적 측정, 지도 이동 등 기능을 제공한다.

16. 커서 모양의 버튼은 선택 기능을 제공하는데, 기본 선택은 레이어를 직접 선택하면 선택된 레이어가 빨간색 원으로 표시된다.

사각형/원형/폴리곤 선택은 Shift 버튼을 클릭한 상태에서 지도 상에 사각형/원형/폴리곤을 그리면 해당 영역의 중간 좌표와 가장 근접한 레이어가 선택되어 빨간색 원으로 표시된다.

17. 고급 선택은 선택할 레이어에 커서를 가져다 대면 해당 레이어 주변으로 파란색 원이 표시되며, 선택하면 선택된 레이어가 빨간색 원으로 표시된다.

18. 핀 모양의 버튼은 포인트 그리기 기능을 제공한다.

19. Point 레이어를 그릴 위치에 커서를 가져가 클릭하면 선택된 위치에 빨간색 점이 표시되고, 저장할 레이어 유형을 선택할 수 있는 드롭박스가 보여져 Point 레이어 유형을 선택 후 저장하면, 추가한 레이어가 지도 상에 조회된다.

20. 선 모양의 버튼은 라인 그리기 기능을 제공한다.

21. Line 레이어 시작지점을 그릴 위치에 커서를 가져가 클릭하면 선택된 위치에 파란색 점이 표시되고, 종료지점을 그릴 위치로 드래그하면 파란색 선으로 연결되면서 종료지점을 더블클릭하면 빨간색 Line으로 보여지며 저장할 레이어 유형을 선택할 수 있는 드롭박스가 보여져 Line 레이어 유형을 선택 후 저장하면, 추가한 Line이 지도 상에 조회된다.

22. 고급 라인 그리기 기능은 라인 그리기와 동일한 방식이나, 그릴 시작지점 및 종료지점에 커서를 가져가면 노란색 원으로 그릴 위치를 가이드 해 준다.

23. 고급 라인 그리기 기능은 라인 그리기와 동일한 방식이나, 그릴 시작지점 및 종료지점에 커서를 가져가면 노란색 원으로 그릴 위치를 가이드 해 준다.

24. 육각형 모양 버튼은 3개 이상의 점으로 구성되는 폴리곤 그리기 기능을 제공한다.

25. Polygon 레이어 시작지점을 그릴 위치에 커서를 가져가 클릭하면 선택된 위치에 파란색 점이 표시되고, 중간지점으로 그릴 위치로 드래그하면 파란색 선으로 연결되면서 클릭 시 라인이 그려지고 종료지점을 더블클릭하면 시작지점/중간지점/종료지점이 연결되는 빨간색 Polygon이 보여지며, 저장할 레이어 유형을 선택할 수 있는 드롭박스가 보여져 Polygon 레이어 유형을 선택 후 저장하면, 추가한 Polygon이 지도 상에 조회된다.

26. 고급 폴리곤 그리기 기능은 폴리곤 그리기와 동일한 방식이나, 그릴 시작지점/중간지점/종료지점에 커서를 가져가면 노란색 원으로 그릴 위치를 가이드 해 준다.

27. 고급 폴리곤 그리기 기능은 폴리곤 그리기와 동일한 방식이나, 그릴 시작지점/중간지점/종료지점에 커서를 가져가면 노란색 원으로 그릴 위치를 가이드 해 준다.

28. 포인트 간의 거리를 측정할 수 있는 기능을 제공한다.

29. 시작점을 클릭하고 거리를 측정하고 싶은 종료점을 클릭 시 거리가 측정되어 지도 상에 표시된다.

30. 고급 거리 측정 기능은 거리 측정과 동일한 방식이나, 측정 대상 출발점/종료점에 커서를 가져가면 노란색 원으로 그릴 위치를 가이드 해 준다.

31. Polygon의 면적을 측정할 수 있는 기능을 제공한다.

32. 시작점을 클릭하고 면적을 측정하고 싶은 Polygon을 그리며 종료점에서 더블클릭 시 해당 Polygon 면적이 측정되어 지도 상에 표시된다.

33 상하좌우 화살표 버튼은 지도 이동 기능을 제공한다.

34. 위로 이동 클릭 시 지도 화면이 위로 이동한다.

35. 아래로 이동 클릭 시 지도 화면이 아래로 이동한다.

36. 왼쪽으로 이동 클릭 시 지도 화면이 왼쪽으로 이동한다.

37. 오른쪽으로 이동 클릭 시 지도 화면이 오른쪽으로 이동한다.

38. 특정 좌표로 클릭 시 좌표를 입력할 수 있는 팝업이 뜨고, 좌표 입력 시 해당 좌표 위치로 지도 화면이 전환된다.

39. 양방향 화살표 버튼은 지도 화면에 대한 확대 및 축소 기능을 제공한다.

40. 확대 버튼 클릭 시마다 지도 화면 Zoom level이 한 단계씩 올라가면서 화면이 점차 확대된다.

41. 축소 버튼 클릭 시마다 지도 화면 Zoom level이 한 단계씩 낮아지면서 화면이 점차 축소된다.

42. 집 모양 버튼 클릭 시 맵 초기 위치로 지도 화면이 이동한다.

43. 지도 화면 회전 기능을 제공한다.

44. 시계 방향 회전 클릭 시 지도 화면이 시계 방향으로 회전 되어 보여진다.

45. 반시계 방향 회전 클릭 시 지도 화면이 반시계 방향으로 회전 되어 보여진다.

46. 톱니바퀴 모양의 설정 버튼으로 레이어 투명도 설정 기능을 제공한다.

47. 투명도 설정을 변경할 레이어 명칭을 선택하고 투명도를 변경 조정한 후 적용 버튼 클릭 시 지도 상의 레이어 이미지의 투명도가 변경된다.

48. 사이드바의 최하단 삼각형 모양의 버튼 클릭 시 사이드바가 숨겨진다.
